# DreamGoods — правила для работы над кодом

- **Версия.** Любое изменение кода сопровождается обновлением версии: `dreamgoods/__init__.py` (`__version__`),
  `frontend/package.json` (`version`) и раздел с этим номером в `CHANGELOG.md`. Это требование владельца проекта, без исключений.
  Номер X.Y.Z:
  - **X — крупное изменение**: новая версия продукта, смена архитектуры или модели работы, несовместимые изменения
    (1.4.2 → 2.0.0);
  - **Y — среднее изменение**: новый раздел или заметная функция сервиса (новая страница, отчёты, оплата) (0.7.3 → 0.8.0);
  - **Z — мелкие правки**: доработки и исправления существующего — вёрстка, тексты, анимации, синхронизация данных,
    исправления ошибок (0.7.2 → 0.7.3).
  - **четвёртая цифра — совсем мелкие правки** внутри уже выпущенной версии: подстройка настроек, моделей, текстов
    (0.7.4 → 0.7.4.1).
  Если сомневаетесь — ставьте меньший разряд.
- **Push только с подтверждения владельца.** Коммитить можно, но `git push` — лишь после явного «да» в чате.
- Ветки: `main` — только релизы с меткой `vX.Y.Z`; `dev` — рабочая; крупные эксперименты — отдельные ветки (например, `dev-ui`).
- Интерфейс собирается в `dreamgoods/web` и хранится в Git — после правок фронтенда пересобрать и закоммитить сборку.
- Ответы владельцу — на русском, пошаговые инструкции текстом в чате.

- **Один артикул — один товар.** При распознавании, проверке групп и подтверждении загрузки одинаковые артикулы объединяются. Запрещено автоматически создавать «Артикул_2», «Артикул_3» для одного распознанного артикула, в том числе из-за другого цвета, ракурса, папки или повторной загрузки. Реально напечатанный артикул с `_2` — отдельный артикул, суффиксы вслепую не отрезать. Сравнение учитывает регистр, пробелы и Unicode-нормализацию. Это правило обязательно проверяется тестами.

- При изменении названий и расположения функций обновлять справку помощника `dreamgoods/ai/assistant_guide.py`. Простой/расширенный режимы меняют только представление, без записи параметров съёмки. Массовые действия используют явные ID товаров и показывают скрытый фильтром выбор.
