# DreamGoods Desktop для Windows 10 (1903+)/11 x64

Установщик `DreamGoods-Setup-0.12.0-x64.exe` собирается в GitHub Actions → **Windows desktop installer** → **Artifacts → DreamGoods-Windows-x64**.
Распакуйте скачанный ZIP, запустите EXE, выберите папку. Права администратора, Docker, Python и Node.js на ПК не нужны.
Запускайте ярлык **DreamGoods**. Первый запуск создаёт отдельную локальную базу; вход новой установки — `admin` / `admin`.
Ключ Polza укажите в настройках приложения. Для работы ИИ требуется интернет и оплаченный ключ.

Установка независима от серверной Dev-GPT: существующие проекты автоматически не переносятся.
Данные находятся в `%APPDATA%\DreamGoodsDesktop` (PostgreSQL, files, logs, exports, database.json).
Закройте DreamGoods и запустите новый установщик поверх существующей установки. Удалять программу перед обновлением не нужно.
Перед первым запуском новой версии существующая база автоматически копируется в `backups/<дата>/database.dump` в формате PostgreSQL. Если копию не удалось создать, миграции не запускаются. Копия содержит базу, но не фотографии: они остаются в `files`. Для полной резервной копии закройте DreamGoods и скопируйте всю папку данных. `database.json` нужен для открытия существующего кластера.
Копии не удаляются автоматически. Для восстановления `database.dump` используется PostgreSQL 17 `pg_restore`; встроенной кнопки восстановления пока нет.
Обновление установщиком сохраняет данные. Удаление программы также оставляет эту папку.
Схема базы обновляется автоматически; не запускайте более старую версию на уже обновлённой базе.
Локальная PostgreSQL 17 слушает только 127.0.0.1, использует случайный внутренний пароль и отдельный свободный порт.
Это внутренний пароль базы: приложение не требует от пользователя менять пароль входа.
При закрытии окно ждёт завершения уже оплачиваемых заданий, затем останавливает свою базу.
Не завершайте процесс принудительно во время обработки: оплаченный запрос может потребовать сверки в «Бюджетах».

Установщик пока без цифровой подписи. Windows может показывать предупреждение об неизвестном издателе.

## Референс в ручном плане

Откройте пресет → план «Вручную» → нужный метод → «Загрузить фото».
Загрузка бесплатна. «Описать с ИИ · платно» запускает разбор в очереди с обычным учётом расходов.
После завершения нажмите «Использовать ИИ-описание» и при необходимости отредактируйте его.
Можно написать описание вручную. Сохраните собственный пресет и примените его к одному выбранному товару.
Фото референса передаётся генератору вместе с фото товара только для кадров этого метода.
Идентичность товара берётся с его оригинальных фото; референс задаёт композицию, свет и настроение.
Главная обложка сохраняет правила площадки. Для свободной композиции выберите площадку «Без правил».
Удаление привязки методом «Убрать» не удаляет исходный референс из коллекции клиента.

## Сборка

На Windows с Python 3.12, Node.js 22 и PostgreSQL 17:

```powershell
pip install -r requirements.txt pyinstaller==6.19.0
cd frontend
npm ci
npm run build
cd ..
# Скопируйте bin, lib, share, doc из PostgreSQL 17 в desktop/vendor/postgresql.
python desktop/prepare_postgres.py desktop/vendor/postgresql
python desktop/smoke_backend.py
pyinstaller --noconfirm desktop/backend.spec
cd desktop
npm ci
npm run dist
```

Сервер, миграции и веб-интерфейс упаковываются PyInstaller. Electron открывает локальный интерфейс с sandbox и без Node.js в окне.
Зависимости Electron фиксируются package-lock.json; сторонние лицензии включены сборщиком Electron и поставкой PostgreSQL (doc).
Скрипт CI проверяет установку EXE, реальное окно, API, первую и повторную загрузку базы, завершение PostgreSQL и изоляцию окна.

## Окна и статус ключа

Desktop использует собственную панель окна. Авторизация открывается в компактном окне, рабочая область — в полном размере. Статус ключа Polza вверху обновляется автоматически каждые 30 секунд, после изменения ключей и при возвращении в окно. Сайт доступен по ссылке в меню аккаунта.

Удаление товаров доступно в карточке и для выбранных товаров; фото и группы можно удалять при загрузке. Активные задания и неопределённые платные результаты нужно сначала завершить или сверить.

Одинаковый распознанный артикул объединяет фото в один товар даже после проверки ИИ, из разных папок и при повторной загрузке. Автоматический суффикс `_2` для одного артикула не создаётся.


## ИИ-помощник

Кнопка «Помощник» внизу справа открывает боковую панель. Нужен основной ключ Polza; ответы платные и отражаются в расходах как «ИИ-помощник». В «Управление → Тех. настройки» можно выключить помощника или заменить модель (по умолчанию `openai/gpt-4.1-mini`).
Помощник получает справку из `dreamgoods/ai/assistant_guide.py`, текущий раздел и текстовые сведения о первых пяти выбранных товарах. Фото и API-ключи в контекст не передаются. Не вставляйте пароли и ключи в сообщения. Диалог не сохраняется в базе и очищается при смене проекта, выходе из аккаунта или закрытии приложения.
Кнопки только открывают разрешённые разделы и профили выбранных товаров. Помощник не запускает генерацию, не удаляет записи и не сохраняет план автоматически. План можно получить текстом и перенести в ручной пресет.
Панель доступна в Desktop; API и компонент подготовлены для дальнейшего подключения в веб-кабинете.
